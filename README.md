Привет! Спасибо за поддержку нашего сообщества! Ниже приведена инструкция по настройке бота.

## ⚙️ Настройка

1. **Подготовьте необходимые данные:**
    * 🔑 **Токен бота** от [@BotFather](https://t.me/BotFather).
    * 🆔 **ID канала** (куда постить) и **ID чата модерации** (где админы жмут кнопки), а также **ID обсуждения канала** (сейчас не используется, может в будущем что-то придумаем!).
    * 👤 **ID админов** (через запятую) для доступа к консольным командам `/sh` и `/py`.
    * 📂 **Путь к БД** (например, `sqlite+aiosqlite:///database.db`).

2. **Конфигурация:**
    * Скопируйте файл `.env.example` в новый файл `.env`.
    * Заполните все поля своими данными.

3. **Запуск:**
    ```bash
    pip install -r requirements.txt
    python bot.py
    ```

## 🛠 Команды для админов
### Для всех админов (в чате модерации)
* `/reply ID текст` — ответить пользователю от имени бота.
* `/ban ID` / `/unban ID` — управление доступом.
### Для админов, ID которых находится в .env
* `/sh команда` — выполнение shell-команд.
* `/py команда` — выполнения Python-кода.
* `/export_db` — экспортирует базу данных бота к вам в чат.
